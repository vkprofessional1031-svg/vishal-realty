# Property Images Folder

Place all property-specific photographs inside this directory.

### Requirements:
- **Filename**: Save images with clear descriptive filenames matching the `"image"` path inside `src/data/properties.json`.
- **Example**: If `src/data/properties.json` points to `/properties/property-1.jpg`, save the corresponding photo inside this folder as `property-1.jpg`.
- **Dimensions**: For a uniform look across listings, keep the aspect ratio of the photos as a portrait 4:5 or standard landscape 4:3.

Currently, all property listings display a clean, beautiful fallback placeholder card (gray background + Lucide Home icon) since real photos are not yet uploaded.
